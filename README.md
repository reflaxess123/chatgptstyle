# ChatGPT Compact Style

CSS-only Chrome extension and Stylus stylesheet for a wider, denser ChatGPT UI.

## Install as Chrome extension

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Click Load unpacked.
4. Select the `extension` folder.

## Use with Stylus

Create a style for `chatgpt.com` and paste `stylus.css`.

## Tuning

Edit the variables in Block 01:

- `--cgpt-chat-max-width`: chat column width.
- `--cgpt-chat-side-padding`: side padding inside turns.
- `--cgpt-message-font-size`: message text size.
- `--cgpt-message-line-height`: message line height.
- `--cgpt-composer-width`: prompt composer width.
